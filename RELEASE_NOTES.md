# Nerkho v1.0.0

Persian-first Windows dashboard for Iranian currency and gold prices.

- Live TGJU polling every second
- Permanent USD, EUR, GBP, AED and 18K gold cards
- Searchable currency list with embedded country flags
- Toman and Rial display modes
- Session chart and daily high/low values
- Rounded borderless dark interface with custom scrollbars
- Correct dark styling for navigation and window buttons

Download Nerkho.exe and run it on 64-bit Windows. The executable includes the .NET runtime; no separate installation is needed.

Internet access is required for price updates. Source prices can remain unchanged between polls; charts contain observations collected during the current session.
